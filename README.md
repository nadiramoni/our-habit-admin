# 🛡️ ক্লাউড অ্যাডমিন প্যানেল (v4.0) — পিসি লাগে না! ☁️

এই প্যানেল **একটাই `index.html`** — GitHub Pages-এ থাকবে আর **সরাসরি তোমার Firebase-এর সাথে কথা বলবে**। কোনো পিসি, কোনো সার্ভার, কোনো `bun run dev` লাগবে না। মোবাইল, ট্যাব, পিসি — যেখান থেকে খুশি লিংকটা খুলে **ইমেইল + পাসওয়ার্ড** দিয়ে ঢোকো।

```
GitHub Pages (প্যানেল)  ←→  তোমার Firebase (Firestore + Auth)
        ❌ পিসির দরকার নেই
```

---

## 🚀 সেটআপ (মোট ৪ ধাপ, একবারই — ৫ মিনিট)

### ধাপ ১: প্যানেল GitHub-এ তুলো
1. GitHub-এ রিপো (যেমন `our-habit-admin`) → এই ফোল্ডারের **`index.html`** আপলোড করো (আগেরটা replace করো)
2. Settings → Pages → Deploy from a branch → main → Save
3. ১–২ মিনিটে লাইভ: `https://তোমার-ইউজারনেম.github.io/our-habit-admin/`

### ধাপ ২: Firebase-এ তোমার github.io ডোমেইন অনুমতি দাও (জরুরি!)
না দিলে লগইনে "unauthorized-domain" এরর আসবে:
1. **Firebase Console** → **Authentication** → **Settings** → **Authorized domains**
2. **Add domain** → লিখো: `তোমার-ইউজারনেম.github.io` (যেমন `nadiramoni.github.io`) → Save

### ধাপ ৩: প্রথমবার অ্যাডমিন হওয়া
1. প্যানেলে ঢোকো → **তোমার নিজের ইমেইল + পাসওয়ার্ড** (অ্যাপে যেটা ব্যবহার করো) দিয়ে লগইন
2. পিন চাইবে → **755** দাও (ডিফল্ট নিরাপত্তা পিন)
3. ব্যস! তোমার অ্যাকাউন্টটা চিরতরে অ্যাডমিন হয়ে গেল ✅ (এরপর পিন আর লাগবে না, শুধু লগইন)

> ⚠️ যে অ্যাকাউন্ট দিয়ে প্রথমবার পিন দাবি করবে, সেটাই একমাত্র অ্যাডমিন। অন্য কেউ পিন জানলেও ঢুকতে পারবে না — কারণ adminUid একবার সেট হলে আর নেয়া যায় না।

### ধাপ ৪: Firestore Rules আপডেট করো (রিপোর্ট + ব্যান চালু করতে)
1. **Firebase Console** → **Firestore Database** → **Rules** ট্যাব
2. পুরোটা মুছে → এই ফোল্ডারের **`firestore.rules`** ফাইলের ভেতরের সব পেস্ট করো → **Publish**
3. এতে: অ্যাডমিন (শুধু তুমি) সব ইউজারের রিপোর্ট পড়তে পারবে + ব্যান করতে পারবে; সাধারণ ইউজার `banned` ফিল্ড কখনো বদলাতে পারবে না।

## 🔐 লগইন (প্রতিবার)

- ইমেইল + পাসওয়ার্ড = **তোমার নিজের অ্যাকাউন্ট** (Firebase Auth যাচাই করে — পাসওয়ার্ড কোথাও জমা থাকে না)
- ব্রাউজার মনে রাখবে — পরেরবার খুললেই সোজা প্যানেল
- 📱 মোবাইল, 💻 পিসি, 🖥️ ট্যাব — যেকোনো ডিভাইস, একই লিংক, একই লগইন

## ❓ সমস্যা হলে

| দেখাচ্ছে | মানে | করণীয় |
|---|---|---|
| "unauthorized-domain" | github.io অনুমতি নেই | ধাপ ২ করো (Authorized domains) |
| "permission-denied" | Rules আপডেট হয়নি | ধাপ ৪ করো (firestore.rules পেস্ট) |
| রিপোর্ট খালি | backups read অনুমতি নেই | ধাপ ৪-এর rules পেস্ট করো |
| "এই অ্যাকাউন্ট অ্যাডমিন না" | অন্য অ্যাকাউন্ট অ্যাডমিন | যে অ্যাকাউন্ট দিয়ে সেটআপ করেছিলে সেটা দিয়ে ঢোকো |
| পিন মিলছে না | পিন বদলানো থাকতে পারে | পুরনো পিসি-প্যানেলে বদলে থাকলে সেটাই দাও; নাহলে Firestore → `app/meta` → `webAdminPinHash` ফিল্ড ডিলিট করলে আবার 755 হয় |
| ব্যান করলেও ইউজার ঢুকছে | ওর APK পুরনো (v3.2-এর আগে) | নতুন APK দিলে ব্যান সাথে সাথে কাজ করবে |

## 📌 মনে রাখো

- এই প্যানেল চলে **তোমার Firebase-এর ফ্রি কোটায়** — ছোট অ্যাপের জন্য ফ্রি লিমিটেই সব চলবে।
- প্যানেলের লিংক পাবলিক হলেও: লগইন ছাড়া কিছু দেখা যায় না, আর অ্যাডমিন হতে হলে তোমার অ্যাকাউন্ট + পিন দুটোই লাগে।
- অ্যাপের ভেতরের গোপন প্যানেল (হোমে নামে লম্বা চাপ) আর `localhost:3000/admin` প্যানেল আগের মতোই কাজ করে — তিনটাতেই এক Firebase।
